My Project

UNZA Cribs: Metric-Based Identity Verification

My final year project is a full-stack web application designed to help University of Zambia students find safe and affordable boarding houses. Built with Node.js, Express.js, and MongoDB, the platform features a custom metric-based digital identity verification system to ensure secure access for both students and landlords.

The system implements a robust 3-factor authentication mechanism, combining password analysis, email-based One-Time Password (OTP) verification, and facial recognition. Each factor is scored, and the scores are combined into a continuous, unbiased "Trust Score" to make access decisions. The platform also includes a comprehensive dashboard for landlords to securely manage their property listings, all protected by this advanced security model.
